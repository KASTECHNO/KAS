🚀 INSTRUCTIONS D'IMPORT SUR HEBERGEMENT:

OPTION 1: Via PhpMyAdmin (Recommandé pour petits hébergements)
─────────────────────────────────────────────────
1. Accédez à PhpMyAdmin via votre panel de contrôle
2. Créez une nouvelle base de données "kas" (charset: utf8mb4)
3. Sélectionnez la base "kas"
4. Allez dans l'onglet "Importer"
5. Cliquez "Choisir fichier" et sélectionnez kas_database.sql
6. Cliquez "Exécuter"
7. Attendez la confirmation ✓

OPTION 2: Via Terminal/SSH (Plus rapide pour gros volume)
────────────────────────────────────────────
1. Connectez-vous en SSH à votre serveur
2. Uploadez le fichier kas_database.sql via SFTP
3. Exécutez la commande:

   mysql -u [utilisateur] -p [base_de_donnees] < kas_database.sql

4. Entrez votre mot de passe quand demandé
5. Attendez la confirmation

OPTION 3: Via Laravel Artisan (Si code Laravel en place)
────────────────────────────────────────────
ssh user@host
cd /chemin/vers/project
mysql -u root -p kas < kas_database.sql

⚙️ CONFIGURATION LARAVEL (Assurez-vous que .env contient):

DB_CONNECTION=mysql
DB_HOST=localhost (ou IP du serveur DB)
DB_PORT=3306
DB_DATABASE=kas
DB_USERNAME=votre_utilisateur
DB_PASSWORD=votre_motdepasse
DB_PREFIX=kas_

IMPORTANT: Le préfixe `kas_` est OBLIGATOIRE dans .env pour que
toutes les relations fonctionnent correctement!
